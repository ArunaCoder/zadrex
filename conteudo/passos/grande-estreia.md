O jogo está pronto. Você programou um xadrez inteiro, com Esquisitos, sons, animações e um computador que joga (mal, mas joga). Agora é hora da parte mais gostosa: a **grande estreia** do Zadrex e o desafio pra família inteira. 🚀

## 1. O jogo explica como se joga

Quem vai jogar não viu você programar. Então o próprio jogo precisa ensinar! Num cantinho do cenário `tela inicial`, escreva com letras pequenas algo assim:

> Clique em JOGAR. Você é o time de baixo. Clique num Esquisito seu pra ver pra onde ele pode ir e clique numa bolinha pra jogar. Dê xeque-mate na Grande Almofada do computador!

## 2. Os créditos

Todo jogo de verdade diz quem fez. Na tela inicial (ou numa fantasia nova da Placa), escreva:

- quem programou (o seu nome ou apelido) e quem ajudou;
- quanto tempo levou;
- um obrigado pra biblioteca do Scratch, se você usou sons ou desenhos de lá.

## 3. Modo estreia: tela cheia

Na hora de jogar, use a **tela cheia**: o botão de quadradinho em cima do palco, à direita. O jogo fica grandão e ninguém arrasta os Esquisitos sem querer. Pra sair, aperte **Esc**.

## 4. Levando o Zadrex pra passear

O Zadrex inteiro cabe num arquivo só: o `Zadrex.sb3`. Quer jogar na casa da vó? Copie o arquivo pra um pen drive. Em qualquer computador com o Scratch instalado, é só abrir o Scratch e usar **Arquivo → Carregar do seu computador**.

## 5. Grave o trailer 🎬

Grave um vídeo mostrando o jogo inteiro, da tela inicial até a placa de vitória, pra colocar aqui em **Olha só como ficou**. É o trailer oficial do Zadrex!

## 6. O Grande Torneio da Família 🏆

Agora, o desafio. Monte uma tabela na geladeira (uma geladeira de verdade, que não voa) e chame todo mundo:

| Jogador | Partidas | Vitórias contra o computador |
|---|---|---|
| | | |
| | | |
| | | |

Algumas regras sugeridas pro torneio:

- Cada pessoa joga 3 partidas contra o computador.
- Quem der mais xeque-mates ganha.
- Empate Sonolento vale meio ponto.
- O campeão escolhe a sobremesa. 🍨
